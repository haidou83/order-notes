02 / Review checklist

Check before you import.

Extracted values should always be checked against the original purchase order.

  1. Compare each SKU, description and quantity with the PDF.
  2. Multiply quantity by unit price and check each line total.
  3. Review tax, discounts, shipping and rounding separately.
  4. Leave missing values blank until they can be verified.
  5. Open the CSV and check that values appear in the expected columns.
03 / Project status

A small experiment, clearly scoped.

A local prototype has extracted the three item rows from this fictional, text-based sample. Other layouts and scanned PDFs have not been validated. There is currently no public upload or conversion tool.

Text-based PDFs contain selectable text. Scanned documents are images and typically require an additional recognition step. Different document layouts may produce different results.
